\# Cumulative Value-at-Risk and Expected Shortfall Forecasting



\*Work in progress.\*



This repository contains MATLAB code for forecasting 10-day-ahead cumulative Value-at-Risk (VaR) and Expected Shortfall (ES), in line with Basel regulatory requirements for market risk.



\## Structure



The code expects the following local folder structure (not included in this repository for data confidentiality reasons):



project/

├── Code/ (this repository)

├── Data/ (not public — restricted-access data)

└── Output/ (generated results, not public)



\## Main entry point



Run `main\_estimation.m` to reproduce the analysis (requires local data, see above).
